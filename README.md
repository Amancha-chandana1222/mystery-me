# 🔍 Mystery Me

### An Interactive Cyber-Futuristic Personal Website

Mystery Me is an interactive, mystery-themed personal website designed to introduce my identity, education, technical skills, interests, achievements, and future ambitions through an investigation-style experience.

Instead of presenting information through a traditional portfolio layout, the website allows visitors to explore different sections, unlock information, and discover details through an immersive cyber-futuristic interface.

---

## ✨ Features

* **Interactive Landing Screen** – An introductory screen featuring an unknown identity concept.
* **Investigation Experience** – A discovery-based navigation experience.
* **Identity Reveal** – Unlock personal information through an interactive visual reveal.
* **Access Level Sections** – Explore personal details, education, skills, and career goals.
* **AI Chandu Terminal** – An interactive terminal with predefined questions and dynamically displayed responses.
* **Mission Control Dashboard** – A visual dashboard displaying skill-related metrics.
* **Classified Dossier** – A digital profile containing personal and educational information.
* **Dossier Download** – Download the resume through the dossier section.
* **Mission Complete Screen** – An ending screen with an option to restart the investigation.
* **Custom Cursor Effects** – An animated cursor experience on supported desktop devices.
* **Responsive Interface** – Designed to support different screen sizes.

## ⚙️ Installation and Setup

### Prerequisites

* Node.js
* npm
* Git

### 1. Clone the repository

```bash
git clone https://github.com/Amancha-chandana1222/mystery-me.git
```

### 2. Navigate to the project directory

```bash
cd mystery-me
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to explore the website.
